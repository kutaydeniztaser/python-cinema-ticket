# 🎟️ Cinema Ticket System

A simple console-based cinema ticket system developed with Python as part of my learning journey.

## 📌 About the Project

This project simulates a basic cinema ticket purchase process.
The user enters cinema, movie and customer information. The program calculates the total ticket price and change, then generates a simple ticket receipt.

## ⚙️ Features

- Cinema name input
- Movie name input
- Customer name input
- Ticket price and quantity input
- Automatic total price calculation
- Customer payment input
- Change calculation
- Random 5-digit ticket number
- Console ticket receipt output

## 🧠 Python Concepts Used

- Variables
- `input()` and `print()`
- `int` and `float`
- Basic arithmetic operations
- Type conversion
- `random.randint()`
- Escape sequence (`\n`)

## 🚀 Purpose

This project was created to practice Python fundamentals by applying them to a simple cinema ticket purchase scenario.
